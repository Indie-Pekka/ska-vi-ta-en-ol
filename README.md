# Ska vi ta en öl?

En liten webbapp för att diskret säga att man är sugen på sällskap.

- Man tänder en signal ("Sugen på en öl"), med dag och valfri plats.
- Vännerna ligger i listor som bara man själv känner till. Listan Alltid inbjudna ser alltid signalen, andra listor väljs för varje signal.
- Den som inte får se signalen ser ingenting – inte heller vilken lista hen ligger på.
- Signalen slocknar av sig själv kl. 02 natten efter den valda dagen.

Prototyp. Webbappen läggs på hemskärmen och använder Supabase för inloggning och data.
